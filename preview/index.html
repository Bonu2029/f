Voice, rules and boundaries

/dashboard/receptionist

Preview plays audio generated by the same provider that answers calls. The built-in safety rules can be switched off but never deleted, and each one maps to a line in the prompt the agent actually receives.

Voice

What it is allowed to do

Book appointmentsChecks real availability, then creates the appointment.
Send text messagesConfirmations and follow-ups to the caller.
Request photosTexts a secure, expiring upload link.
Transfer calls to a personHands the caller over when they ask.

Receptionist rules

  • Never invent prices Built in

    Only quote prices stored in the services list.

  • Never invent availability Built in

    Only offer times returned by the calendar tool.

  • Answer truthfully about being AI Built in

    Never claim to be human.

  • No same-day installations

    Installations need at least three business days.

What runs, and what needs your credentials

Pricing is driven by one table: Founding Member at $20 with 200 minutes while spots remain, then AI Front Desk at $49 with 500. Adding a plan later means adding an entry, not changing the schema.

Working now

  • Signup, email verification, login and password reset
  • Multi-tenant database with row-level security enforced by Postgres
  • Eight-step onboarding that resumes where you left it
  • Training conversation that writes real, editable business knowledge
  • Inbound call routing, tool execution, transcripts and summaries
  • Leads, appointments, SMS and customer photo uploads
  • Founding 50 with concurrency-safe slot reservation
  • Stripe checkout, webhooks, usage metering and overage reporting
  • Admin console with audit logging and no impersonation
  • 114 automated tests, including real-database integration tests

Needs an account before it can leave demo mode

  • Supabase project — database, auth and file storage
  • Stripe — to take an actual payment
  • Twilio — to buy a number and send real texts
  • OpenAI — for the realtime voice and text models
  • Google Cloud — only if you want calendar booking

Every one has a real adapter already written and a clearly-labelled development mock. SETUP.md lists each credential and the dashboard steps that cannot be scripted.
